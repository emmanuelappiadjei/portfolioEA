# Legacy design system

`styles.css` and `script.js` are the stylesheet and script from the previous
version of this portfolio (release 2026.08.20.3, the blue/off-white "v13"
direction). Nothing in the current site references them.

They are kept here rather than deleted so the earlier visual direction stays
recoverable. Every piece of *content* from that build — projects, case-study
copy, metrics, landing pages, and email work — was carried into the current
site; only the presentation layer was replaced.

Safe to delete once you're confident you won't want the old look back.
